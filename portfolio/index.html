Security Engineering Portfolio

Portfolio · 2026 · Ioannis Alexander Konstas

A working security lab, documented the way I would document it for a client: what each tool does, why it exists, how it is built, and which controls it satisfies. Everything here runs on infrastructure I own, and every test targets only systems I am authorized to test.

Most portfolios show finished screenshots. This one shows the engineering underneath: the scripts that attack my own services to prove the defenses hold, the tools that measure a network instead of guessing about it, and the audits that turn a laptop into evidence. The series starts with the control plane that ties them together, then goes deep on each toolkit.

The Series

1 · From Scripts to a Security Control Plane

Four hundred security scripts behind one web console: Ansible, Semaphore and a hardened Kubernetes cluster, with run history, schedules and inline blast-radius warnings.

Overview · Ansible · Semaphore · Kubernetes

2 · Pentest Toolkits: Attacking My Own Stack on Purpose

Self-penetration testing, IDS live-fire with evasion variants, an analyzer-to-blocklist pipeline, post-quantum attack simulation, an OWASP file scanner with four threat-intel lookups, and a pentest report generator.

Pentest · IDS/WAF · Post-Quantum · OWASP

3 · Network Testing: Measuring Instead of Guessing

IPv6 Neighbor Discovery and EUI-64 tooling, jitter and bandwidth measurement, DHCP and WHOIS diagnostics, DNS-leak verification, TLS hardening and multi-console lab sessions.

Network · IPv6 · DNS · TLS

4 · Hardening & Monitoring: Turning a Machine into Evidence

A 13-domain macOS forensic and vulnerability assessment, network forensics, live log monitors, an SSH regression suite, encrypted vaults and educational factoring algorithms.

Forensics · Hardening · SSH · Cryptography

5 · Threat Hunting: Reading a SIEM Like an Investigator

Hunting in a self-hosted Wazuh SIEM: the dashboard and events views, rule levels, MITRE ATT&CK mapping, DQL queries that open an investigation, correlation rules for custom feeds, and tuning.

SIEM · Wazuh · MITRE ATT&CK · Detection

6 · Hybrid Cloud Platform: A Private Overlay WAN, Kubernetes and Everything as Code

The capstone: a WireGuard overlay that behaves like a private Metro Ethernet service, one Kubernetes cluster across cloud and office, servers in OpenTofu, hardening in Ansible, an in-house PKI and one automation console.

Capstone · WireGuard · k3s · OpenTofu · Ansible · PKI
