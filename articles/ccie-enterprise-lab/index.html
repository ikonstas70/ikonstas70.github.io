How to Use This Workbook

Study Guide

Recommended Order

  • Start with Labs 01–03 (L2/EIGRP/OSPF) for foundations
  • Progress through Labs 04–05 (BGP + Multicast)
  • Build the transport layer: Labs 06–08
  • Security and services: Labs 09–13
  • Study SDI conceptually: Labs 14–15
  • Finish with automation: Labs 16–18

Lab Environment

  • Cisco Modeling Labs (CML) — recommended
  • EVE-NG Pro — IOS XE 17.x images
  • GNS3 — with IOS XE qemu images
  • Minimum RAM: 16 GB for full topology
  • IOS XE version: 17.6+ required
  • Labs 14–15 need DNA Center / SD-WAN

Lab Structure

  • Initial configs — start here (IPs only)
  • Task sheet — CCIE-style exam tasks
  • Verification — exact show commands
  • Key concepts — theory and why
  • Troubleshooting — common mistakes
  • Solution — type SOLUTION to reveal
