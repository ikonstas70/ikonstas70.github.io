Prerequisites & Requirements

General Requirements (All Scripts)

  • Windows — these scripts are Windows-only
  • PowerShell 7.0+ — install from winget install Microsoft.PowerShell
  • RSAT AD Module — Windows 10/11: install from Optional Features
  • Domain membership — host must be joined to the target AD domain
  • Run as Administrator — all scripts require elevated privileges
# Install RSAT on Windows 10/11
Add-WindowsCapability -Online `
  -Name 'Rsat.ActiveDirectory.DS-LDS.Tools~~~~0.0.1.0'

# Install RSAT Group Policy tools (GPO scripts)
Add-WindowsCapability -Online `
  -Name 'Rsat.GroupPolicy.Management.Tools~~~~0.0.1.0'

Domain Controller Only

  • Invoke-ADSnapshotManager requires a Domain Controller
  • Needs ntdsutil.exe and dsamain.exe (installed with AD DS)
  • Snapshot creation requires sufficient VSS storage space
  • Mount operations require a free TCP port (default: 50000)
  • Use Invoke-Command -ComputerName <DC> to run remotely
# Check VSS storage
vssadmin list shadowstorage

# Verify ntdsutil is present (on DC)
Get-Command ntdsutil.exe

# Run snapshot manager remotely
Invoke-Command -ComputerName DC01 -ScriptBlock {
  & ".\Invoke-ADSnapshotManager.ps1" -Action List
}

Database Recovery

1 script
Essential — DC Only
Invoke-ADSnapshotManager.ps1
Manages the complete Active Directory database snapshot lifecycle using the built-in ntdsutil snapshot facility and dsamain.exe. Enables object-level and attribute-level recovery from a point-in-time snapshot without rebooting any domain controller or performing an authoritative restore. This is the preferred recovery path for accidentally deleted or modified AD objects in Windows Server 2008 R2 and later.
  • New-ADDatabaseSnapshot — Create a VSS snapshot of the live NTDS database with disk space pre-check
  • Get-ADDatabaseSnapshot — List all available snapshots via ntdsutil; optional VSS query mode
  • Mount-ADDatabaseSnapshot — Mount snapshot on a free LDAP port via dsamain.exe with 30s ready wait
  • Dismount-ADDatabaseSnapshot — Stop dsamain and unmount the snapshot cleanly
  • Remove-ADDatabaseSnapshot — Permanently delete old snapshots (requires -Commit)
  • Repair-ADObjectAttribute — Restore a specific attribute value from snapshot to live directory (dry-run default)
  • Repair-ADUserGroupMembership — Restore a user's group membership delta from snapshot (dry-run default)
DC Only Dry-Run Default PS7 Native
