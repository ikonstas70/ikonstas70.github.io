A2Billing VoIP Billing Engine: Architecture, AGI Integration, and Rate Management

Articles · 2026 · Ioannis Konstas

← All Articles

How A2Billing integrates with Asterisk via AGI for real-time call billing, rate deck structure, calling card IVR flow, and MySQL database schema.

What Is A2Billing

An open source VoIP billing and management platform built for Asterisk — AGPLv3, free for commercial use.

A2Billing handles prepaid and postpaid billing, calling card management, DID provisioning, reseller accounts, and customer self-service. It integrates with Asterisk via the AGI (Asterisk Gateway Interface) — intercepting calls in the dialplan to check balances, authorise calls, and deduct credit in real time.

AGI Integration in the Dialplan

; extensions.conf — A2Billing called before every outbound call
[from-pstn-inbound]
exten => _NXXNXXXXXX,1,AGI(a2billing.php,1)
exten => _NXXNXXXXXX,n,Dial(PJSIP/${EXTEN},30)
exten => _NXXNXXXXXX,n,Hangup()

[outbound-calls]
exten => _1NXXNXXXXXX,1,AGI(a2billing.php,1)
exten => _1NXXNXXXXXX,n,Dial(PJSIP/${EXTEN}@carrier-trunk,60)
exten => _1NXXNXXXXXX,n,Hangup()

When Asterisk executes AGI(a2billing.php,1), A2Billing: looks up the customer account, checks the balance, looks up the rate for the destination prefix, calculates the maximum allowed call duration, and sets an Asterisk channel variable. If the balance is zero or the destination is not in any rate deck, the call is rejected before connecting.

Rate Deck Structure

Rate decks define what the platform charges per minute to each destination prefix.

-- Example rate entries (cc_rate table)
destination         | prefix | rate_usd_per_min
--------------------|--------|------------------
USA Domestic        | 1      | 0.0120
Mexico Mobile       | 5219   | 0.1800
Dominican Republic  | 1809   | 0.0850
Brazil Mobile       | 5511   | 0.2200
UK Landline         | 4411   | 0.0250

Prefix matching is longest-match — a call to a Brazil mobile (5511...) will match the 5511 prefix over the generic 55 Brazil entry. Multiple rate decks can exist for different customer tiers (retail, wholesale, reseller).
